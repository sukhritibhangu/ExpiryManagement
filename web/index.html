Where do I get it, and where does it go?
  1. Open aistudio.google.com/apikey and sign in with any Google account.
  2. Click Create API key → pick or create a project → copy the key that starts with AIza.
  3. Paste it in the Gemini API key field above and press Save (or Enter).
  4. Press Test — it verifies the key against Google and lists the vision models your key can reach.
  • The key is stored only in this browser's localStorage under geminiApiKey. It is never sent to this app's server.
  • Free tier is enough for label scanning; if you see a quota error, wait a minute or use Offline OCR.
  • If Google replies “API has not been used in project … or it is disabled”, enable the Generative Language API for that key's project in Google Cloud Console.
  • No key? Switch to Offline OCR — Tesseract runs entirely in your browser.
